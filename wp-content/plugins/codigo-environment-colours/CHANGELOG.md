
# Change Log
All notable changes to this project will be documented in this file.
 
The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## [1.1.1] - 2026-11-24

- Udpate staging colour set

## [1.1.0] - 2026-11-24

- Added a native WordPress settings page.
- Added configurable production and staging URLs.
- Removed all Mulroy-specific references.
- Renamed the custom colour scheme to codigo-gold.
- Renamed functions using the codigo_ prefix.
- Added URL validation and sanitisation.
- Added protection against identical environment URLs.
- Added a current environment indicator on the settings page.
- Retained the original staging CSS and toolbar badges.
- Restricted configuration to users with the manage_options capability.

## [1.0.0] - 2026-11-24


- Initial project-specific implementation with hardcoded environment domains.
- Sunrise production scheme and custom gold staging scheme.
- Environment labels in the WordPress toolbar.
